发布日期：2026-11-03

## 这是什么

Covenant 是**面向人机协作的软件工程契约图示工具**：`.cvn.yaml` 单源事实 → 确定性 SVG/HTML 渲染 → 图上批注（人机分工明确）→ 补丁门禁与写前审计 → 可交付单文件/文件夹站点。

## 下载

- `covenant-kit-0.1.0.zip`（可移植包，Node ≥20，无需 pnpm/网络）
- `covenant-kit-0.1.0.zip.sha256`

## 亮点

- **契约校验**：`covenant check`（schema + 剖面 + 引用/ID 唯一性）
- **确定性渲染**：布局/标签/端口/接线 stub 可复现，黄金 SVG 防回归
- **查看器**：单文件离线 HTML（零外部请求），点选/悬浮窗/📌钉住/缩放拖拽/批注编辑/删除撤销
- **批注与写回**：human-only 状态流转；`serve --edit` 一键写回 `.cvn.yaml`（`.audit` 写前审计 + 备份）
- **补丁门禁**：`patch-check` / `apply`（base_rev、AI 只能加批注、不得改 ai_hint/status）
- **文件夹站点**：`covenant bundle` → `index.html + manifest.json + views/*.svg + annotations.json`
- **FRAS 索引 + ADR**：`pnpm index` / `pnpm adr` 门禁
- **可交付包**：`pnpm package:kit` 产出单文件 CLI（esbuild 打包）+ 预构建查看器 + 模板/示例/文档/schema

## 快速开始（kit）

```bash
node bin/covenant.mjs check templates/team-starter
node bin/covenant.mjs build templates/team-starter -o out/covenant.html
node bin/covenant.mjs serve out --edit --open     # 图上改批注 → 写回
node bin/covenant.mjs bundle templates/team-starter -o out/site
```

## 已知边界

- 查看器离线单文件；编辑写回需本机 loopback 服务（`serve --edit`）
- 批注不直接改文件：导出补丁或经本地服务写回，AI 不能改状态/人类字段
- 仅 Node 20+ ESM CLI；Windows/macOS/Linux
- 未发布 npm 包（首个版本以 Release zip 交付）
