# Covenant v0.3.0

架构契约图语言：`.cvn.yaml` 单一事实源 → 确定性 SVG/HTML 看板 → 人工批注 → 补丁门禁落盘。

## 交付物

| 文件 | 说明 |
|---|---|
| `covenant-kit-0.3.0.zip` | 可移植工具包（Node ≥ 22，无需 pnpm/网络） |
| `covenant-kit-0.3.0.zip.sha256` | 校验和 |

解压后：

```bash
node bin/covenant.mjs check templates/team-starter
node bin/covenant.mjs build <你的架构目录> -o out/covenant.html
node bin/covenant.mjs serve out --edit --open   # 在线加批注并写回
```

## 本次新增

**格式 / 内核**
- `mixed@1` 混合剖面：20 种元素类型可在同一文档共存（对接旧架构图的多类型混用）
- `impl_status`：5 态（implemented / partial / planned / not_connected / unknown）→ 线型映射，关系按弱端继承
- `evidence[]`：`{kind: doc|code, path, lines}` 结构化证据链，看板可展开、可复制路径
- `segment` 段级批注：多段边的每一段可独立批注（schema / gate / render / viewer 全链路）
- patch 协议扩展：`add|remove /elements/*`、`/relations/*` 完整支持（gate 校验 + apply 写回 YAML）

**看板（viewer）**
- 多小窗并存 + 8 色确定性配色 + 同色引导线；悬停 120ms 预览、点击保留、📌 钉住
- 拖拽小窗期间抑制所有 hover/click 判定，不再误触发其它元素
- `✓` 核验标记：顶栏按钮切换状态，图上渲染绿色圆标，导出补丁携带核验结果
- 「新增批注」表单：`[保存] [取消]` 位于标题行，底部不再有滚动按钮
- 回收桶默认折叠；侧栏按 自身架构 / 系统契约 / 示例演示 / 模板 分组并支持搜索
- compact 布局（无标签胶囊）；交点用空心圆表示几何交叉、实心圆仅表示 T 型连接

**工程治理**
- `AGENTS.md`：Lead 派发契约 L1–L11（含工作区边界）
- `scripts/agent/team_audit.mjs`：A0–A8 漂移审计（派发记录字段、幽灵 owner、版本一致性、决策索引等），带**基线机制**区分存量债务与新违规，并配自测防"审计被改松"
