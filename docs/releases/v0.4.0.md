# v0.4.0 — 图上编辑闭环 + 写回增强

> 发布日期：2026-11-05 · 上一版本：v0.3.0 · 语义化版本：minor（新功能，向后兼容）

## 一句话

架构图看板从「只能看 + 标批注」升级为「图上直接增删元素与关系」，且写回链路首次完成端到端验证。

## 新能力

### 图上编辑（全部走补丁通道，AI/人权限边界不变）

| 操作 | 入口 | 行为 |
|---|---|---|
| 建元素 | 双击画布空白 | 表单（name/kind/summary/tech）→ 暂存 → 导出补丁或写回 |
| 删元素 | 选中 + Delete | 暂存删除（降饱和 + 可撤销）；被批注/关系/框引用时拒绝 |
| 建关系 | 元素窗口 **⇒ 连线** → 点目标元素 | 表单（kind/summary）→ 暂存 `add /relations/-` |
| 删关系 | 选中边 + Delete | 暂存删除；被批注引用时拒绝（防悬空引用） |

暂存都实时反映在图上（虚线占位 / 降饱和）与顶栏计数；「导出补丁 JSON」「导出全部补丁」「写回」自动携带。

### 写回增强

- 写回前自动 `GET /api/rev` 取服务端真实 rev 并 rebase——连续写回不再被 `patch/stale` 拒。
- 「导出全部补丁」输出 `covenant-all.patches.json`，配 `covenant apply-bundle` 一次落盘多文档。

### 治理与认知（面向协作者）

- `pnpm granularity`：文件粒度棘轮（新文件 ≤300/400 行，存量只减不增）。
- `pnpm agent:audit`：A1–A9 派发漂移审计（版本单一事实源 A9、派发记录与 Lead 自记行合并判定）。
- AOCI 仓库认知层：独立实例 + 194 文件全量认知索引（`aoci verify` aligned）。

## 修复

- 画布平移/小窗拖拽期间误触发其它元素悬浮窗（指针封印状态机补 `panning`）。
- ✓ 核验按钮静默失效（作用域 `doc` 未定义 + `docId`/`key` 失配）。
- **E9**：`covenant apply` 关系 add 被写进 elements 块（改走 `appendRelations`）；门禁元素 add 误用 relation 词表。
- CLI 版本号三处硬编码漂移（收敛 `COVENANT_VERSION`，审计 A9 强制）。

## 升级

kit 内模板与命令不变；解压新 kit 替换旧目录即可。已在用 0.3.0 写回的团队：无迁移项（patch 格式未变，本次修复只影响落盘位置的正确性）。

## 复跑验证

```bash
pnpm install
pnpm verify            # 0 error · 386 tests
pnpm build:html && pnpm run build:bundle
pnpm package:kit       # dist/covenant-kit-0.4.0.zip + sha256
```

交互项（双击建 / ⇒ 连线 / Delete 删 / 写回）需在真实浏览器点检（jsdom 不能替代）。
