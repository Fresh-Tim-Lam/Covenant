# 采用单文件自包含 HTML

## 背景

契约图需要人直接打开审查并标注问题。引入构建服务器、外部 CDN 或前端打包产物都会让"打开就能看"变成"先装环境"。

## 决策

`covenant build` 输出**单个自包含 HTML**：内联 SVG、内嵌语义 JSON、内联脚本与样式，零外部请求。

## 后果

- 好：双击即用、可邮件/IM 传输、离线可读、易做归档与 diff。
- 坏：文件体积较大（当前 ~100KB 级）；无法按需加载大型图；脚本 CSP 受限。
- 约束：任何新增渲染能力都必须保持"无外部依赖"。

## 备选

- 构建服务器 + 前端应用：需要部署与鉴权，违背本地工具定位。
- 依赖 CDN 的单 HTML：离线与安全不可控。
